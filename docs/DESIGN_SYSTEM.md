# Visual and interaction system

## Format

The product is a **single-screen immersive real-time monitoring terminal**. It should fit the viewport like an instrument panel, not behave like a long marketing page.

## Visual rules

- dominant background: near-black;
- monochrome phosphor green/blue-gray with restrained warning amber;
- IBM Plex / monospace terminal typography;
- thin borders, tiny labels, scanlines, faint grid, controlled glow;
- no glossy cards, neon gradients, generic SaaS dashboard styling, or cartoon mascot treatment;
- exactly eight soft, irregular octopus arms;
- animation is sprite/canvas decoration and must respect `prefers-reduced-motion`.

## Layout contract

- header: brand, chain, AI router, phase, modules, data age, X link, connection state;
- ticker: ATTACH / OBSERVE / REMEMBER and truth-layer labels;
- specimen panel: side-view swimming octopus, phase, module register, ASK entry;
- Directive 01: chain input, latest block, transaction count, latency, target identity;
- Directive 02: eight arm registry, moods, states, divergence;
- Directive 03: retained lifecycle memory, high/baseline/health;
- lifecycle feed: filterable `ALL / CHAIN / RULE / SYSTEM`, with origin labels;
- footer: phase, scope, chain, token, data age, AI invocation mode.

## Truth-aware UI

The UI must visibly distinguish:

- real chain data;
- connected external catalog facts;
- deterministic rule analysis;
- on-request AI interpretation;
- system/infrastructure status;
- visual-only motion.

If target activity is zero, display `VERIFIED ZERO ACTIVITY`; do not create a fake wiggle. If a layer has no records, say that the layer is quiet while monitoring continues.
