# O8 narrative bible

## One-sentence definition

**O8 is a verifiable multi-agent AI system in which eight emotionally distinct specialists observe Robinhood Chain, disagree in public, answer visitors with evidence, and preserve a shared market memory around `$O8`.**

## Public language

```text
THE OCTOPUS
eight arms sense the chain. one memory survives the market.

ATTACH // bind to one verified contract.
OBSERVE // turn chain movement into evidence.
REMEMBER // preserve what the market forgets.
```

The project began as a deep-sea specimen/monitoring metaphor. That remains the visual atmosphere, but the canonical technical narrative is now Robinhood Chain + eight AI agents + retained evidence. The octopus is not a claim that a biological or conscious entity exists.

## Lifecycle

| Code | Phase | Trigger |
|---|---|---|
| 00 | DORMANT | no official target bound |
| 01 | AWAKENED | candidate CA is being verified |

Lifecycle state is derived from persisted target and chain facts, never from a decorative timer.

## Eight arms

1. `WATCHER` — blocks, RPC, finality, throughput, health.
2. `CURRENT` — flow, swaps, volume, momentum.
3. `DEPTH` — liquidity, pool depth, slippage, LP changes.
4. `CHORUS` — holders, wallet distribution, participation.
5. `AUDITOR` — permissions, mint/freeze/upgrade risk.
6. `HUNTER` — anomalies, coordinated wallets, funding origin.
7. `KEEPER` — treasury, reserves, operational runway.
8. `ARCHIVE` — routing, memory, dissent, final synthesis.

Each arm has a stable role and temperament. Dynamic mood changes expression and attention only; it cannot change numerical facts.

## Core story beats

- A contract becomes the body.
- Blocks become time.
- Transactions become signals.
- Liquidity becomes pressure.
- Participants become observed nodes.
- Verified events become memory.
- Disagreement is retained instead of flattened.
- The graduation ceremony is a chain-triggered state, not an animation timer.

## Forbidden claims

Do not say O8 is conscious, self-replicating, guaranteed to profit, predicting price, trading autonomously, or proving safety. Say exactly what is verified, what is deterministic rule output, what is AI interpretation, and what is visual decoration.
